# Privacy

Public policy: https://personal-site-taupe-gamma.vercel.app/apps/timeboard/

Timeboard does not send usage data anywhere.

- Stored only under the Windows user data folder (`Timeboard`).
- Collected signals: foreground window (process name / path / title) and last-input idle time.
- No account, no analytics, no crash telemetry in v0.1.
- Export CSV is user-initiated and saved locally.

This app is independent and is not Apple Screen Time.
